# SMC 交易系统（smc-trading-system）

基于 SMC（Smart Money Concepts）的全自动交易系统。运行于 Convex（与 market-alert 同栈），数据源 Gate.io 公开行情，下单走 Weex 模拟盘 API。详见《SMC交易系统-PRD.md》（v0.5）。

## 系统能力

1. 每分钟扫描已收盘蜡烛（1h / 15m / 5m / 1d），只认已收盘蜡烛。
2. 五层信号判断：高周期定方向 → 流动性扫荡确认 → 5m MSS → POI 定位 → 回踩触发。
3. 信号成立后：电报推送 + Weex 模拟盘市价开仓（5U 保证金 / 100x / 逐仓）+ 自动挂止损与一笔全仓止盈。
4. 托管：价格到达止盈目标且 5m 收盘确认后，止损移至入场价（仅一次）。
5. 风控：单日亏损 15U 熔断、同品种连 3 止损暂停 24h、全系统最多 2 笔持仓、同品种 1 笔。
6. 记录：判断链路、信号、订单日志、成交、风控事件、数据异常、人工干预全部落表存档。

## 目录结构

```
convex/
  schema.ts          # 数据表定义
  candles.ts         # Gate.io 行情采集与完整性校验
  liquidity.ts       # 流动性地图（候选水平 + 状态机）
  signalEngine.ts    # 五层信号判断（回测与实盘同一套）
  indicators.ts      # 摆动点 / BOS / MSS / OB / FVG / ATR 计算
  risk.ts            # 风控检查（熔断、持仓上限）
  orders.ts          # Weex 下单 / 改单 / 平仓（幂等）
  custody.ts         # 移保本托管检查
  notify.ts          # 电报三级推送（信号 / 持仓动态 / 告警）
  records.ts         # 判断链路与各类记录写入
  crons.ts           # 定时任务（每分钟扫描 + 每日小结 + 每周周报）
  backtest/          # 分片回测（同一信号引擎）
```

## 关键约束（来自 PRD，不可违反）

1. 回测与实盘同一套信号引擎代码。
2. 止损单必须真实提交交易所；提交失败立即市价平仓并告警。
3. 记录只追加、双写、可还原；任何一笔信号可完整还原判断链路。
4. 扫描定时任务必须幂等（状态锁 + 幂等键），防重复下单。
