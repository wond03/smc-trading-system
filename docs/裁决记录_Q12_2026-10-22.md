## 3. 三个阻塞项已确认（2026-10-22）

### 3-1 周期映射 → 4H 定方向 + 30M 执行
原三处表述不一致（Q12 文档「4h/30m」／PRD §10.2「日线+1H」／代码「1H + 5m/15m」）。本人裁决 **以 4H/30M 为目标口径**，改动：
- `scanner.ts` · `SCANNED_INTERVALS`：`["1d","1h","15m","5m"]` → **`["4h","30m"]`**（Q24 定案，1d/1h/15m/5m 全部停采）
- `signalEngine.evaluate()`：`candles5m / candles15m / hourlyLiquidity` → `candles30m / fourHourLiquidity`
- `indicators.ts`：`SWING_N=3` 写死 → 改为按周期参数化：**4H 左右各 3 根（≈±12h）、30M 左右各 6 根（≈±3h）**（Q24）
- `backtest/backtest.ts` 取数周期同步改，历史样本全部重跑

### 3-2 背离模块 → 一期做，作为扳机分支
代码与 PRD 原本均无背离。本人裁决：**一期新增背离层，可替代「流动性扫荡」作为入场扳机**。含义：
- 层 2 由「必须有扫荡」改为「扫荡 **或** 背离」二者其一
- 背离单仓位减半（Q22）；止损取背离低点（Q16）；跨品种背离仅加分（Q20）
- 新增：15M 背离检测、「前后背离 / 结构位背离」按时段切换
- 范围影响：+1 指标模块 +1 扳机分支，属**范围变更**，需补登 PRD §3.1
