## 一、策略框架："SMC 2.0（基金版 SMC）"（转写提取）

基本思路（作者口述）：
> "一旦价格向某个方向形成结构突破，就等它回调到前一段走势中的关键价位，然后等价格在这个位置出现特定信号，再入场交易。"

**第一步：确定方向偏见**（15 分钟市场结构）
- 只看市场结构：低点不断降低 + 向下结构突破＝看空；高点不断抬高 + 向上结构突破＝看多。
- 原本多头、收盘价跌破前低＝CHoCH 转空；随后出现向下结构突破＝确立空头。
- 他称用固定规则识别高低点，并编成了"市场结构指标"自动标注。

**第二步：找到关注区域（POI）——该视频最大特点**
- 等价格回到前一段波动区间（摆动高点到摆动低点）内的关键价位才考虑做单。
- **用成交量分布（Volume Profile）定 POI**：在摆动高点—摆动低点区间找**成交量峰值/密集区**；进一步细化到控制点（POC）附近、价值区低点、伦敦时段高点对应的成交量密集位；"最不理想的位置最后才尝试、不太想在那里做"。
- 也提到可用 OB，但他认为**成交量分布比单看订单块更好用**。
- 明确"**不做突破交易**"，只做回调到关键区的单。

**第三步：确认信号（1 分钟图）**
- 价格到关键位后要看**强烈反应**（明显受阻回落）。
- 切 1 分钟图：原本 SMC 要求出现 CHoCH；该体系（"SMC 2.0"）有时用 **MSS**（找买卖双方最近一次交锋位置，一方胜出后又被跌破＝对方重新掌控，作为确认）。
- 实际入场依据可选：成交量分布、FVG、反向 FVG、OB。他本例用"5 分钟大阳线（大量买盘被卖方压倒、后被向下突破的那根）"作为入场依据，等价格回到那根线价位触发入场单。
