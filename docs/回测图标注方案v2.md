# 做单图标注方案 v2（按查尔斯体系重写）

> 依据：14 结构与画图 / 03 体系规则 / 01 easy4RR / 15 概念规则。
> 核心原则：图不是「事件标签堆」，而是讲一个**结构故事**——「抓到了哪里的流动性 → 要去抓哪里的流动性 → 转在哪里确认 → 为什么在这进、损为什么放这」。

## 图的叙事链（五步，替代原来的五层标签）

### 第 0 步：大级别语境（图顶部一条带）
- 4H 图缩略：标出当前 4H 的「结局」（被扫/突破）和路径方向（先上后下/先下后上）。
- 一句话字幕：「4H 空头趋势，上方结局已发生 → 期望抓下方流动性」——这是他盘前的第一判断。

### ① 流动性地图（核心，替代原「扫荡三角」）
- **已经抓掉的流动性**：前低/前高/等低点位置画 ✕（抓到 = 那个位置的挂单被吃掉），注明「上周亚盘低点」「9:30 低点」这类**位置身份**，不是抽象价格。
- **要去抓的流动性**：顺方向下一站画 ⭕（目标），同样标身份（前高、等高点、昨日 POC）。
- 图上一眼看到「✕ 在下面已抓 → ⭕ 在上面要去抓」——这就是「做单两要素」。

### ② 结构段落 + 转（替代原「MSS 紫字」）
- 按他的画图规范画**结构线**：高低点取收线回头根（不是插针），只有 BOS 才换段。
- 段与段之间用折线连接（路径图：先上后下还是先下后上）。
- 「转」的位置标注在**两点（结局点与被结局点）之间的极值**上，若两点间又发生新 BOS，转要推移过去——这才是他说的「画这里就错了」的修正逻辑。
- 卡转状态要写出来：「卡转，未转空 → 看多」。

### ③ 入场区 + 确认（替代原「FVG 色块」）
- FVG 画区间，但重点标注**回踩且踩住**（确认踩住才算，01 篇原话「唯一参考是 FVG 回踩且需确认踩住」）。
- 确认形态写出来：收针收上来/背离出现——「没有结构就不进场」。
- 挂单位置留空间的逻辑：「挂在这里，太高了就没有可以赚的空间」——入场价与上方空间的关系要可见。

### ④ 止损 + 它的逻辑（替代原「红线」）
- 止损位置注明**为什么**：「背离低点下方（高成交量区，价格不会回来）」。
- 画出止损与背离低点/主力区的关系，不是一条悬空红线。

### ⑤ 目标路径 + 持仓管理（替代原「结果一行字」）
- 路径箭头：先过高成交量区间 → 打第一个流动性 → POC 回踩 → 第二个流动性（03 篇的目标路径）。
- 持仓管理节点：1:1 上保、平一半、保护推紧（图上用小旗标出这些动作发生的位置）。

## 图面布局
